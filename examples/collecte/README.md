# Collecte de copies manuscrites

- `selection.json` : les 24 problèmes confiés aux volontaires, avec l'énoncé et la solution acceptée
  recopiée (texte de référence pour mesurer la lecture), l'auteur, le lien et les volontaires assignés.
- `selection.py` : sélection reproductible depuis le catalogue (variété de domaines et de notations,
  solutions complètes uniquement).
- `catalogue_mathwoods.py` : extraction polie du catalogue (robots.txt respecté).
- `problemes.json` + `verifier_solutions.py` : 6 problèmes de calcul/récurrence vérifiés de bout en
  bout dans Lean (référence de ce que le vérificateur couvre aujourd'hui).
